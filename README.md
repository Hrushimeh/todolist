## Note

The goal of this project was to create a to-do list with task priorities considered. One of the other goals was to display missing priorities.

## Getting Started

First, to get dependencies:

```bash
npm install 
```

Then to run the development server:
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open the localhost with your browser to see the result.



## Demo
The application allows you to enter new tasks with the green "+" button, and removed them with the red 'x' button. You can see missing properties by hovering over the blinking red icon on the first task (its a bit buggy), or when adding new tasks.
